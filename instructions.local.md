## Repository-local documentation

- Before making substantial changes to repository-local documentation (`README.md`, `docs/*`, and similar tool-repo docs), first review the relevant managed `canonical-doc` and `decision` documents in project-memory.
- If the documentation change is part of active tracked work, also review the related `work-item`.
- Apply this rule to meaningful documentation rewrites or structural edits, not to trivial typo fixes or similarly small copy-only changes.
